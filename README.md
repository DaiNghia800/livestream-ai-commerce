# livestream-ai-commerce

Nền tảng Livestream AI Commerce. Frontend Next.js nằm trong `apps/web`.

```sh
cd apps/web
npm ci
npm run dev
```

Mở http://localhost:3000 (khách hàng) hoặc http://localhost:3000/shop (chủ shop).
Khuyến nghị Node.js 22, npm 10+. Xem [hướng dẫn frontend](docs/frontend-guide.md).

Luồng Git: `feature/*` → PR `dev` → PR `main`. Backend và hạ tầng chưa triển khai.
